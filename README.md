# CareGrid SA (Team: Careforge)
**Geekulcha Annual Hackathon 2026 (#GKHack26) — Gov Innovation Track**

### Overview
CareGrid SA is a secure, privacy-first Progressive Web App (PWA) designed to protect the human infrastructure of public service delivery in South Africa. It combats chronic occupational burnout among frontline workers (teachers, nurses, social workers) through:
1. Anonymous Peer-Support Pods
2. Contextual Resource Routing (Gauteng regional nodes & verified helplines)
3. Leadership Burnout Heatmaps

### Tech Stack
* Frontend: React, TypeScript, Tailwind CSS
* Backend & Security: Node.js, Supabase (Security-by-Design anonymization protocols)
